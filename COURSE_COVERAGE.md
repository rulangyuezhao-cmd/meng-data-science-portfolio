## How dates are labelled

The term and course title follow my November 11, 2026 academic history. Month ranges identify the academic session, not the exact start and finish of each assignment. University of Toronto SGS defines Fall as September–December, Winter as January–April, and Summer as May–August ([session definitions](https://www.sgs.utoronto.ca/policies-guidelines/graduate-courses-other-academic-activities/)). For the industry project and safety workshop, the table records when credit appeared; it does not imply continuous work throughout that session. Portfolio reconstruction in November 2026 is separate from the original course dates.

## Coverage boundaries

All programs advertised as runnable in this repository have a common execution path and automated checks. This does not mean every experiment, scraping job, cloud session, or original submission has been recovered. Each technical course README identifies the preserved concepts and the adaptations made for portability. A new SQL companion is labelled separately from recovered coursework. No dropped course is presented as completed.
