# CHE1800Y — MEng Project

Credit recorded Summer 2026. CMTE industry project with Wolseley Express.

I developed and piloted a computer-vision checkout application for wholesale parts, covering **107 SKUs** and achieving **94.5% whole-frame accuracy on 2,905 validation images**. The workflow combined model development with a usable application and operational evaluation.

Technologies documented in my project experience include Python, PyTorch, YOLO, FastAPI, Azure APIs, Git, Azure DevOps, and Docker. This supports my experience translating an ML model into an engineering workflow.

The company dataset, application code, infrastructure settings, and credentials are not part of this public coursework collection.
