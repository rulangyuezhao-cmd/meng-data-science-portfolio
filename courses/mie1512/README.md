# MIE1512H — Data Analytics

Completed Winter 2026. My ReasonEval project is maintained in its existing repository:

**[mie1512-reasoneval-portfolio](https://github.com/rulangyuezhao-cmd/mie1512-reasoneval-portfolio)**

The project evaluates reasoning in 3,400 mathematical solutions from 12 language models, using saved ReasonEval inference outputs and human annotations. Follow that repository's setup and notebook instructions to run the CPU analysis. The original GPU inference notebook remains missing; this collection does not claim to reproduce the full scoring pipeline.

The existing repository is linked rather than duplicated, preserving its project narrative, datasets and history.
